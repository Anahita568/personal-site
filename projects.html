Art Log In progress GitHub

Purpose: A personal art cataloging tool: save pieces encountered across any medium, tag them along independent axes (medium, movement, mood, color, subject), and filter the collection by any combination of tags.

Tech stack: Spring Boot, Spring for GraphQL, PostgreSQL, Java 21, React, TypeScript, Apollo Client, Vite.

Current phase: Backend and frontend both functional locally: composable multi-axis tag filtering, full CRUD on artworks (add/edit notes/delete), catalog-style UI. Not yet deployed.
