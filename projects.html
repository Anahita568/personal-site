Event Recommendation Agent GitHub

Art Log Live GitHub

Purpose: A personal art catalog: save pieces across any medium, tag them along independent axes (medium, movement, mood, color, subject), and filter by any combination of tags. Visitors browse read-only; editing is owner-only.

Tech stack: Spring Boot, Spring for GraphQL, PostgreSQL, Java 21, React, TypeScript, Apollo Client, Vite, Cloudinary. Deployed on Render, Neon, and Vercel.

Current phase: Live and in use. Next: multi-user accounts so others can keep their own catalogs.
